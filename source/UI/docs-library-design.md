# 文献库页面设计文档

> 最后更新：2026-08-17

## 一、整体定位

像「专业知识资料库」，而不是普通文件列表。

进入「文献库」后，中间主区域展示：

- 标题：文献库
- 说明：管理与浏览知识图谱和问诊过程中使用的研究文献
- 搜索栏 + 轻量筛选 + 排序
- 两列文献条目列表

**核心原则**：一篇文献 = 一个横向信息单元，两列排列提高浏览密度，但不像传统 Card Grid 那样有厚重边框和阴影。整体更接近 Editorial / Research Library。

## 二、页面顶部

### 第一行

- 左侧：
  - 文献库（标题）
  - 收录并管理用于疾病知识分析与智能问诊的研究文献（说明）
- 右侧：
  - + 添加文献（主按钮）

主按钮色值：

- 默认：#8C6B5D
- Hover：#6B5045

### 第二行：搜索与轻量筛选

- 搜索框占位符：🔍 搜索文献标题、作者、关键词……
- 快捷分类标签：全部文献 | 疾病研究 | 诊断 | 治疗 | 机制

建议不做传统复杂筛选器，采用「搜索优先 + 少量快捷分类」。

标签样式：

- 默认背景：#FAF3EC
- 默认文字：#6F6763
- 选中背景：#8C6B5D
- 选中文字：白色

## 三、核心：两列「文献条目」

推荐布局：左缩略图 + 右信息。

每个文献条目结构：

- 左侧：PDF 首页缩略图
- 右侧：
  - 标题
  - 作者 · 年份 · 来源
  - 摘要（2-3 行）
  - 关键词标签

两列布局，行与行之间保持清晰节奏。

## 四、弱化「卡片感」

不要：

- 厚重阴影
- 明显浮起
- 大圆角
- 很重的白色卡片

采用：

- 默认背景：transparent / #FDFBF7
- 底部极浅边框：#EDE5DD
- 或极轻：rgba(255,255,255,0.55) + #EDE5DD 边框 + 12px 圆角

Hover：

- 背景轻微变白
- border-color 轻微加深
- 非常轻的阴影
- 整个条目不明显位移

视觉方向：文献资料铺陈在知识工作台上，而非电商商品卡片。

## 五、缩略图

- 宽：110～130px
- 高：150～170px
- 采用真实 PDF 首页预览
- 边框：#EDE5DD
- 圆角：8px
- 无预览时：统一占位封面（米白背景、暖灰文字、小面积品牌暖棕）
- 不要彩色 PDF 图标

## 六、文献信息层级

每篇文献最多五层：

1. **标题**
   - 18px
   - #3E3836
   - Medium / Semibold
   - 最多 2 行
2. **作者 + 时间 + 来源**
   - 例如：Pedersen NC · 2023 · Journal of Feline Medicine
   - 颜色：#6F6763
   - 字号：13px
3. **摘要**
   - 只显示 2～3 行
   - 颜色：#6F6763
4. **关键词**
   - 例如：[猫传腹] [FIP] [诊断]
   - 背景：#FAF3EC
   - 文字：#8C6B5D
5. **来源信息（可选）**
   - DOI / PMC / PubMed / citations
   - 降低视觉优先级

## 七、布局尺寸

- 最大内容宽度：1440px
- 两列之间 Gap：32px
- 每列最小宽度：500px
- 响应式：窗口 < 1100px 时自动切换为单列

## 八、最终视觉方向

将「左侧单列的巨大文献流」改造成「暖杏奶油风格的双列研究资料库」。

整体视觉：

暖白背景 #FDFBF7
        ↓
简洁的「文献库」标题
        ↓
搜索栏 + 少量分类标签
        ↓
两列文献流
        ↓
每条 = PDF 首页缩略图 + 文献核心信息
        ↓
极浅分隔线，而不是厚重卡片
